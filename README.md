# 🌿 MIDORI — Artisan Matcha & Boba Atelier

Website resmi gerai kuliner artisanal **MIDORI**, terinspirasi dari keanggunan budaya teh Uji Kyoto dan kenikmatan boba modern.

## ✨ Fitur Utama
- **Aesthetic Modern UI**: Desain bernuansa warm earthy & matcha green dengan tipografi elegan (Playfair Display & Plus Jakarta Sans).
- **Responsive Layout**: Tampilan optimal di perangkat smartphone, tablet, dan desktop.
- **Diferensiasi & Identitas Eksklusif**: Tampilan terinspirasi dari referensi namun diperkaya dengan identitas visual mandiri, fotografi produk resolusi tinggi, dan micro-interaction yang hidup.
- **Interaktif Order & Customizer Modal**: Kustomisasi tingkat manis (*sugar level*), tingkat es (*ice level*), jenis susu (*oat/dairy/almond*), serta ekstra *topping*.
- **Slide-out Shopping Cart Drawer**: Keranjang belanja interaktif dengan kalkulasi diskon kupon (`MIDORI20`).
- **Direct WhatsApp Checkout**: Otomatis menyusun draf rincian pesanan dan mengarahkannya ke barista via WhatsApp.
- **Dual Currency Switcher**: Konversi mata uang dinamis antara IDR (Rp) dan USD ($).
- **Store Locations Modal**: Informasi lengkap outlet di Jakarta, Bandung, Bali, dan Surabaya.

## 🌐 Deployment (Vercel)
Website ini adalah static web application murni (zero-dependency build). Dapat langsung di-deploy melalui Vercel CLI atau GitHub Integration:
1. Hubungkan repository GitHub: `https://github.com/hands-boop/kuliner.git` ke akun [Vercel](https://vercel.com).
2. Framework Preset: **Other** / Static.
3. Root Directory: `./`
4. Klik **Deploy**.
